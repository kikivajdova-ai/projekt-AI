# Návrh obrazovek

Klikací prototyp obrazovek aplikace (ukázková data, bez napojení na backend).
Soubory jsou ve formátu plátna Claude Design (`.dc.html`) a slouží jako záloha a historie návrhu.

| Soubor | Obrazovka |
|---|---|
| `Main.dc.html` | aplikace se spodní lištou: Domů (8 chvilek sám/sama nebo s kamarádem), Přátelé, Zahrada (roste s každou chvilkou), Já |
| `Sdileni.dc.html` | náhled před sdílením („Takhle to uvidí ostatní“) |
| `Nalada.dc.html` | záznam nálady; nejnižší hodnota vypne hru a nabídne pomoc |
| `Pomoc.dc.html` | linky pomoci 116 123, 116 111, 155, 112 s ilustrací zahrady |
| `canvas.json` | rozložení plátna |
